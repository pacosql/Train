27   1. Introduction
28
         Adaptive educational systems aim to provide students with individualized learning materials and thus
                                                    M

29
30   to increase efficiency of the learning process. Specific examples of educational systems that incorporate
31   adaptive behaviour and have been shown to increase efficiency of learning are Cognitive Tutor (Ritter et al.,
32   2007) and Math Spring (Arroyo et al., 2014).
                                         D


33       In order to achieve adaptivity, systems need to be able to estimate the skill of students and difficulty
34   of educational materials (items, questions, problems). One possible way to obtain skill estimates is to use
35   models from item response theory (IRT). These models were, however, developed in the context of comput-
                                      TE




36   erized adaptive testing and are typically based on the assumption of a constant skill. Another possibility
37   is to use specialized models for modeling learning (Desmarais and Baker, 2012), e.g., Bayesian knowledge
38   tracing (Corbett and Anderson, 1994) or Performance factor analysis (Pavlik et al., 2009). All these models,
39   however, are not easy to use: they may require calibration on large samples using nontrivial parameter
                             EP




40   estimation or are hard to use in an online educational system. These aspects make the development of
41   adaptive systems more complicated, time consuming, and expensive.
42       An interesting alternative to specialized models is the Elo rating system (Elo, 1978). This system
43   was originally proposed for rating chess players; for an overview of the history of chess rating systems
                 C




44   see Glickman (1995). The basic principle of the system is simple: each player is assigned a rating, this
45   rating is updated after each match, the update is proportional to the surprisingness of the match result.
              AC




46
     If a strong player beats a weak player, the results is not surprising and the update is small; whereas if
47
     the opposite happens, the update is large. The system has been extended in many ways, the most well-
48
49   known extensions are Glicko (Glickman, 1999) and TrueSkill (Herbrich et al., 2006). Nevertheless, even
50   the basic Elo rating system is still widely used for rating many contests, online games, and sports, e.g.,
51   football (Hvattum and Arntzen, 2010). The system provides a foundation for adaptive behaviour of gaming
52   sites as it can automatically select opponents of similar skill. Moreover, the Elo rating system can be used
53   not just for rating players. It has been used for rating patterns in the game of Go (Coulom, 2007), eliciting
54   user preferences (Hacker and Von Ahn, 2009), assessing security and vulnerability risks (Pieters et al., 2012),
55   or for ranking posts in online forums (Das Sarma et al., 2010).
56       We can use the Elo rating system in educational systems if we interpret a solution attempt as a match
57   between a student and an item. This approach provides an easy way to estimate the skill of students and

41   4.2. Estimation of Prior Skill
42       For estimating prior skill we make a simplifying assumption that both students and items are homoge-
43
     neous – we assume that we can model students’ overall prior knowledge in the domain by a one-dimensional
                 C




44

45
     students with different backgrounds it would be necessary to extend the used model or to make predictions
              AC




46
47   for different groups of students independently. The homogeneity of items is addressed below.
48       We model students’ prior knowledge of geography as a single global skill θs ; difficulty of geography items
49   is modeled by a difficulty parameter di . For estimation of these parameters we use the basic Elo rating
50   system with the uncertainty function U (n) = a/(1 + bn), where n is the number of previous answers and
51   a, b are meta-parameters. Using a grid search we have determined optimal values a = 1, b = 0.05. This
52   exact choice of parameter values is not important, many different choices of a, b provide very similar results.
53   Figure 4 shows difficulty estimates for several countries. The figure illustrates how the Elo rating system
54   with an uncertainty function provides both fast coarse estimates after few answers and stability in the long
55   run. Estimates by the Elo rating system with the uncertainty function U (n) = a/(1 + bn) are also very
56   similar to estimates obtained by a more principled Bayesian approach to modeling uncertainty (Nižnan
57   et al., 2015).

22

                                                      AN

26       In this setting we use the extension of the Elo rating system with learning (i.e., asymmetric update in
27   the case of correct and incorrect answer). It is also useful to incorporate forgetting, particularly when we
28   are modeling declarative knowledge (in contrast to procedural skills, which are the typical focus of student
                                                     M

29   modeling). We can do this by using time from previous attempt. We can model short term memory effect in
30   the following way: the skill is “locally” increased by f (t) where t is the time (in seconds) between attempts.

32   et al., 2014) or a generic staircase function fitted to data (Pelánek, 2015). It should be possible to further

42
43       To conclude, we provide a summary discussion of the Elo rating system and guidelines for its application
                C




44   in the practical development of adaptive educational systems.
45
             AC




46   5.1. When is the Elo Rating System Applicable?
47       In educational applications the Elo rating system is suitable mainly for adaptive practice or low stakes
48
     testing. The system provides reasonable estimates that are sufficient for guiding adaptive behaviour, but
49
     does not provide statistical guarantees on estimated skills (as opposed to well calibrated IRT models used
50
51   in computerized adaptive testing).
52       The Elo rating system is particularly attractive when we want to build a reasonably behaving system
53   quickly and cheaply. It allows us to get adaptive behaviour without expensive expert input, since the system
54   can estimate difficulty of items (questions, problems) and skills of users just from data. Of course, to be
55   able to learn from data, it needs to have enough data available. As our analysis and previous experience
56   shows, the system needs at least 100 students to get good estimates of item difficulty.
57
58
59                                                          10
60

 1
 2
 3       Typical examples of potential applications of the Elo rating system are in domains with simple structure:
 4   learning of factual knowledge, foreign language vocabulary, or practice of basic skills (e.g., arithmetic). More
 5
     complex domains, involving for example prerequisite relations among skills, require more involved student
 6
     modeling approaches (Desmarais and Baker, 2012) or a novel extension of the Elo rating system.
 7
 8       The Elo rating system is attractive particularly for medium sized target groups, e.g., elementary and
 9   high school knowledge for speakers of smaller languages or company vocational training. In these cases it
10   is usually not feasible to construct sophisticated educational systems by experts, particularly in the context




                                                                                               PT
11   of fast changes of the technological landscape. At the same time these target groups are sufficiently large
12   to enable the ‘learning from data’ approach. The use of the Elo rating system provides a way to implement
13   adaptive behaviour quickly and cheaply.
14




                                                                                             RI
15   5.2. What are the Advantages of the Elo Rating System?
16       To appreciate advantages of the Elo rating system it is useful to compare it to alternative approaches
17   to skill estimation. Basic item response theory models assume a constant skill. These models are thus




                                                                                  SC
18   applicable only for short tests (where we do not expect learning) or for modeling very “coarse-grained” skills
19
     (where the overall learning is slow). We can model fined-grained skill and learning over short term using
20
     models like Bayesian Knowledge Tracing or Performance Factor Analysis. These models, however, make
21
     specific assumptions about learning. The Elo rating system is flexible – it can model changing skill, but does
22



                                                               U
23   not make fixed assumptions about the nature of learning. Since the Elo rating system does not make any
24   specific assumptions, it should not be expected to bring an optimal performance for a particular situation.
                                                            AN
25   But it can be easily applied in a wide range of situations and provides reasonable accuracy. The system is
26   also easy to modify for different situations, e.g., the use of multiple choice options or incorporation of timing
27   information.
28       A practically important advantage of the Elo rating system is that it is very simple to implement.
                                                           M

29   The basic Elo rating system needs to store just a single parameter for each student and each item; these
30   parameters are updated after each answer using simple equations. The system requires us to set only the
31   parameter K (respectively the uncertainty function) – other student models typically have more parameters
32   and require calibration or complex parameter fitting.
                                            D


33       The use of the Elo rating system allows easy updating of the content of the education system. When we
34   change or add a new item into the system, we just (re)set its difficulty to 0 and the system learns the item
35
                                         TE




     difficulty from students’ answers. Overall, the application of the Elo rating system is cheap as it requires
36   expert input neither for domain knowledge nor for implementation.
37
38
     5.3. Which Variant of the Elo Rating System is Preferable?
39
                               EP




40      The reported experience suggest that the basic version of the Elo rating system extended with a simple
41   uncertainty function U (n) = a/(1 + bn) provides a good starting point (e.g., with values a = 1, b = 0.05;
42   once enough data are collected these values can be easily fitted using a grid search). More complex variants
43   can improve performance, but the improvement is often small and may not be worth the increase in imple-
                 C




44   mentation complexity. It is useful to focus only on extensions which are particularly suited for a specific
45   educational application (e.g., incorporation of response times in the case of mathematics).
